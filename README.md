# HÆ?! — Norwegian for Real Life
Launch landing page for the Kindle book.

## Local
npm install
npm run dev

## Deploy
Import this repo into Vercel or run `vercel` after linking the project.

## Analytics
Uses `@vercel/analytics`. Events: `amazon_click` with location, and `phrase_generator_click`.

## Social preview
`public/og-image.jpg` is 1200×630 and configured in Next.js metadata.
